# Archive

Superseded material, kept for reference. Nothing on the site or in `scripts/` uses it.

- `scripts_old/`: earlier versions of the build scripts (unversioned originals, v4, v5, v2.2,
  v2.4) and one-off steps from earlier dataset updates. The current scripts are in `scripts/`.
- `copy_review/`: the scripts and notes from the plain-language review of the figure copy. The
  renderer still in use is `scripts/copy/render_copy_v2_5.py`.
- `data_v4/`, `figures_v4/`: data and figures from the v4 extraction.
- `mockups/`: design options considered for the site.

These scripts still point at their old locations (`docs/dex_hff/`), so they won't run from here
without changing their paths.

`raw_old.zip` (local only, not in git) holds the superseded raw datasets: v2.2, v2.4.1, the v2.4
share, the v4 extraction workbook and the original pipeline files.
